# @hkpd/competition

Lõi C01–C05/C09/C10: draw KO/vòng tròn, hạt giống, lifecycle, transfer, scheduler/lane helpers, transaction ports và projection Match A03. React UI C06–C08 trong apps/web. Xem [bàn giao nhóm C](../../docs/group-c/README.md) về quy tắc nguồn, adapter, UI và giới hạn nghiệm thu.

`npm run check` build và kiểm thử; mặc định CSPRNG, RNG cố định chỉ dùng cho tests/fixtures. Không có SQL, OAuth, route nghiệp vụ hay tác dụng bên ngoài trong package này.
