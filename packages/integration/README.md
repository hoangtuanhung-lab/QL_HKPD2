# @hkpd/integration

Cầu nối server R/C/K và consumer B05 trước nhóm I. Đọc [báo cáo rà soát](../../docs/review/pre-i.md) và [contract adapter](../../docs/review/integration-contract.md). Package chỉ có pure domain/projection và transaction ports; chưa mount API, cung cấp memory store production hoặc gọi SQL/Google/Netlify.
