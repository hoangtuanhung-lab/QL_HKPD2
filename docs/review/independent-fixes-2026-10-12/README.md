## Dữ liệu cũ và browser support

- Dùng khóa mới `hkpd.a04.school-drafts.v2` chứa envelope formatVersion2, revision và stable local draft IDs; portable JSON export vẫn formatVersion1 và không có server IDs/approval state.
- Khi chưa có v2, đọc v1 hiện có. Chỉ ghi v2 sau lock/CAS thành công, giữ nguyên bytes v1 để đối chiếu. Token raw bytes phát hiện legacy thay đổi dù revision vẫn0. Không tự merge bằng họ tên hoặc xóa các VĐV trùng tên.
- Tab chạy code cũ tiếp tục ghi vào key v1, không ghi đè key v2. Sau cập nhật cần tải lại các tab cũ; thay đổi v1 sau migration không tự trộn vào v2, có thể xuất/đối chiếu từ tab cũ. Không hứa tự hợp nhất chỉnh sửa từ nhiều phiên bản app.
- Browser thiếu Web Locks không fallback sang read/write không atomic: giữ bản trong phiên, báo không lưu an toàn và yêu cầu xuất trước khi đóng. Web Locks cần browser/context hỗ trợ; không dùng kiểm tra môi trường test trong production code để bypass.
- Khi conflict/quota xảy ra, writer dừng các lần ghi tiếp theo của phiên đó, không rebase tự động lên dữ liệu khác. Xuất bản đang sửa rồi tải lại/đối chiếu để tiếp tục. Cảnh báo beforeunload giúp nhắc, không phải bảo đảm cứu dữ liệu khi browser/thiết bị crash.

## Hợp đồng và giới hạn

A03/types được generate lại; thêm declaration cho helper validator dùng trong test TypeScript. Ví dụ VĐV hiện có giữ nguyên. Client đọc PublicResult cần narrow athlete/team trước dùng athlete_code. Nhãn public lấy từ metadata authoritative; không coi labels client hoặc kết quả helper là quyền công khai.

Decimal cũ có leading zeros cần rà/correct tại nguồn trước nhập/confirm/public; không tự rewrite official lịch sử hay fingerprint để tạo test xanh. Kiểm reference hiện chỉ đảm bảo hình dạng; tồn tại/scope/snapshot thực đấu/BTC hủy vẫn phải do adapter authoritative xác minh ở bước tích hợp.

Chưa mount business API, dispatcher worker, chia sẻ state R/C/K/I trên các màn hoặc triển khai provider. Chưa triển khai các cải tiến optional như offline bootstrap, XLSX, solver lịch, undo. Không thêm mock store dùng cho production để giả vờ đã có persistence thật.

Xem [verification.json](verification.json) sau full check/smoke/secret scan. SQL static có sẵn không phải SQL thật. Các probe lịch sử dùng API saveDrafts v1 có thể fail sau thay signature/lỗi được sửa; regression mới là oracle hiện tại.
